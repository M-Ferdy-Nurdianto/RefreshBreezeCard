# Refresh Breeze Members Card Portal

This repository contains the landing page for **Refresh Breeze** and individual member card websites.

## Directory Structure

- `aca card/`: ACA's member card project.
- `channie card/`: CHANNIE's member card project.
- `cissi card/`: CISSI's member card project.
- `piya card/`: PIYA's member card project.
- `index.html`: Main landing page (Static).
- `style.css`: Landing page styles.

## How to use

The landing page links to the `dist` folders of each member project. To view a member card, navigate to its respective `index.html` within the `dist` folder.
